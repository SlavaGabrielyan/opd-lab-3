# Документация игрового фреймворка

## Назначение проекта
Проект представляет собой игровой проект для 2D-игры в жанре экшен-платформера, совмещающей элементы "Castlevania" и "Chrome Dino Game". Проект разработан на игровом движке Godot Engine (.NET версия) с использованием языка программирования C#

## История изменений проекта
Опираясь на историю коммитов можно выделить основные этапы развития проекта:

1. **Initial commit и базовая структура** (`693cc80`, `178b999`, `182c739`, `f616679`, `01d9d11`):
   * Создан репозиторий, добавлены базовые файлы проекта и документация по выполнению задания студентами (`README.md`)

2. **Переход на новый движок и язык** (`e3fe1ca`):
   * Полностью стёрта старая логика
   * Проект переписан с нуля под Godot (.NET версию) на языке C#
   * Написана логика для игрока (`Player`) и снарядов (`Bullet`)

3. **Построение системы наследования** (`caac63a`):
   * Сделана основа для системы наследования игровых сущностей
   * Оставлены задачи для реализации конкретных классов.

4. **Реализация игрового мира и сущностей** (`80e34f6`):
   * Созданы конкретные классы для врагов (`Enemies`) и препятствий (`Obstacles`)
   * Создана и собрана основная геймплейная сцена (`Field.tscn`)

5. **Полировка геймплея и пре-бета** (`227b0f8`, `c87c96f`):
   * Отредактировано пару параметров для более лучшего гемплея
   * Сделана финальная заготовка перед релизом
   * Финальная документация для студентов (`c87c96f`)
